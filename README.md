# ME - 个人档案生成器

> 🚀 通过友好的分步引导，创建属于您的 SOUL.md 个人档案

[![Astro](https://img.shields.io/badge/Astro-4.x-BC52EE?logo=astro)](https://astro.build)
[![License](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

## ✨ 特性

- 🎯 **分步引导** - 6 步简单操作，从基础信息到社区集成
- 🔄 **跨平台导入** - 支持从 GitHub 一键导入公开资料
- 🦞 **龙虾社区集成** - 轻松配置跨平台 ID，实现信息快速同步
- 📄 **SOUL.md 生成** - 标准化的个人档案 Markdown 文件
- 💾 **本地存储** - 数据保存在浏览器本地，无需上传服务器
- 🎨 **精美主页** - 自动生成美观的响应式个人主页

## 🚀 快速开始

### 前置要求

- Node.js >= 18.0.0
- npm >= 9.0.0

### 1. 安装依赖

```bash
npm install
```

### 2. 启动开发服务器

```bash
npm run dev
```

访问 `http://localhost:4321` 开始使用 ME 工具。

### 3. 构建生产版本

```bash
npm run build
```

构建产物在 `dist/` 目录。

## 📖 使用指南

### 创建个人档案

1. 访问首页，点击"开始创建"
2. 按照 6 步向导填写信息：
   - **步骤 1**: 基础信息（姓名、职位、简介等）
   - **步骤 2**: 社交链接（GitHub、LinkedIn、Twitter 等）
   - **步骤 3**: 技能专长（技术类别和熟练程度）
   - **步骤 4**: 项目经历（项目描述、技术栈、亮点）
   - **步骤 5**: 工作经历（公司、职位、成就）
   - **步骤 6**: 社区集成（龙虾社区等平台 ID）
3. 在预览页面查看效果
4. 导出 SOUL.md 或其他格式

### 快速导入

#### 从 GitHub 导入

1. 在向导第一步点击"从 GitHub 导入"
2. 输入 GitHub 用户名
3. 自动获取头像、简介、仓库列表等信息

#### 从文件导入

1. 支持导入已有的 `profile.json` 文件
2. 拖放或选择文件即可自动解析

### 导出格式

| 格式 | 说明 | 用途 |
|------|------|------|
| **SOUL.md** | 标准化 Markdown | 开源社区个人档案 |
| **JSON** | 结构化数据 | 程序处理、备份 |
| **YAML** | 人类友好格式 | 配置文件 |

## 🦞 龙虾社区集成

ME 工具专为龙虾社区优化，支持：

- 配置多个龙虾社区平台 ID
- 预设社区标签
- 一键生成社区可用的个人简介

## 🛠️ 技术栈

- **[Astro](https://astro.build/)** - 静态站点生成器
- **原生 CSS** - 无 CSS 框架依赖
- **LocalStorage** - 客户端数据持久化
- **GitHub API** - 公开资料导入

## 🌐 部署

### Vercel（推荐）

```bash
npm install -g vercel
vercel --prod
```

### GitHub Pages

1. 修改 `astro.config.mjs`：

```javascript
export default defineConfig({
  site: 'https://yourusername.github.io',
  base: '/me',
  // ...
});
```

2. 推送代码并启用 GitHub Actions 自动部署

```markdown

## Identity (身份识别)
- Name: 
- Title:
- Location:
- Avatar:

## Bio (个人简介)
...

## Connect (社交链接)
...

## Skills (技能专长)
...

## Projects (项目作品)
...

## Experience (工作经历)
...

## Lobster Communities (龙虾社区)
- Platform: ID

## Meta
- Generated by: ME Tool
- Version: 1.0
```
